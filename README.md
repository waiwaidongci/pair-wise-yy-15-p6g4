# 鸽棚训放台账（hxyfront-62014）

面向赛鸽棚的**离线可用**训放台账前端工具。无需后端，所有档案、训放、归巢登记与配对关系保存在浏览器本机（localStorage），Service Worker 预缓存应用外壳，断网后仍可打开使用。

## 功能

- **新建训放**：填训放地点、放飞距离、放飞时间、天气；距离自动归档短距离（<100km）/ 中距离（100–300km）/ 长距离（≥300km）。
- **按足环登记归巢**：支持先登记“已放飞、暂未归巢”，归巢后再补时间；同场足环去重。
- **分速自动计算**：分速（m/min）= 距离 ÷（归巢时间 − 放飞时间），时间无效或倒序不产生成绩。
- **待核名单**：健康异常（登记时勾选或档案处于异常期）或血统未建档的鸽子进入待核，**不参与排行**；待核页可直接补血统快速建档。
- **排行榜**：跨场次按分速排序（同分先到先排），可按距离档、血统筛选并搜索足环号，筛选条件自动保存。
- **催查提醒**：放飞超过 24 小时仍未归巢显示“催查”，24 小时内归为“飞行中”。
- **单羽档案**：合并该羽历次训放、均分速/最佳分速统计与当前配对关系；配对为一对一，调整时双方原配对自动解除。
- **持久化**：增录、编辑、筛选、移除、配对调整全部即时写入本机，离开页面再回来仍在。
- 顶栏可一键“恢复演示数据”。

## 技术栈

React 19 + Vite 7 + TypeScript（localStorage + Service Worker 离线缓存）
