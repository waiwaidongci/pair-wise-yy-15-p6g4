# 鸽棚训放台账（离线可用）

面向赛鸽棚的训放记录前端工具。纯前端 React 应用，数据保存在本机浏览器
（localStorage），首次访问后由 Service Worker 缓存外壳，**断网也能打开和使用**，
无需后端、无需登录。

## 功能

- **新建训放**：填地点、放飞距离（公里）、放飞时间、天气。
- **按足环登记归巢**：扫描/输入足环号 + 归巢时间 + 归巢健康；
  档案里没有的足环会自动建档（血统留空，进入待核）。
- **分速自动计算**：分速（米/分）= 距离 × 1000 ÷ 用时，录入时实时预览，保存即用。
- **待核名单**：健康异常或血统未建档的鸽子自动进入待核，**其成绩不参与排行**；
  可补录血统、标记恢复正常。
- **成绩排行**：按分速自动降序；可按**距离档**（短 <100km / 中 100–300km /
  长 >300km）、**血统**、足环号筛选；被排除的成绩单列展示并注明原因。
- **催查提醒**：放飞超过 **24 小时**仍未归巢的，在总览和批次里显示“催查”及超时时间。
- **单羽档案**：合并该羽历次训放（距离档、天气、归巢、用时/分速）与**当前配对关系**；
  支持增录、编辑、筛选、移除档案，以及配对调整（自动解除旧配对、避免三方关系）。
- **持久化**：增录、编辑、筛选、移除、配对调整等所有改动都会写入 localStorage，
  离开页面再回来（含刷新、关页重开、断网）数据与筛选状态都还在。
- 移除档案时历次训放登记保留，可在“待核名单 → 档案缺失的登记”里恢复档案或清理。

## 技术栈

React 19 + Vite + TypeScript，无额外运行时依赖；离线缓存用原生 Service Worker。

## 本地运行

```bash
npm install
npm run dev      # 开发：http://localhost:62014
npm run build    # 生产构建（输出到 dist/，含 sw.js）
npm run preview  # 预览生产构建
```

## 测试

```bash
npm run typecheck  # TypeScript 类型检查
npm test           # 纯逻辑单测 + jsdom 端到端冒烟（无需浏览器）
```

- `scripts/check-logic.ts`：分速、距离档、排行排除规则、24 小时催查、统计口径。
- `scripts/smoke.tsx`：从新建训放到归巢登记、排行筛选、待核处理、档案编辑/配对/移除、
  以及“销毁重挂”模拟离开再回来的持久化校验。

## 数据与隐私

所有台账数据仅保存在当前浏览器的 localStorage（键名 `pigeon-loft-ledger-v1`），
不会上传到任何服务器；清除浏览器站点数据会一并清空台账。
